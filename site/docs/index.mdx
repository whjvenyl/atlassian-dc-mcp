## How a request flows

<Steps titleSize="h3">
  <Step title="Caller presents a PAT" icon="key-round">
    `X-Confluence-PAT` / `X-Jira-PAT` per product, or `X-Atlassian-PAT` for both. No credential → `401` before any tool runs.
  </Step>
  <Step title="Identity resolved from the token" icon="fingerprint">
    `/rest/api/user/current` on your DC instance (cached 5 min, keyed by a credential hash). Never a client-supplied header.
  </Step>
  <Step title="Policy intersected" icon="git-branch">
    Effective scope = PAT's DC permissions ∩ global cap ∩ user rules. Layers only ever narrow.
  </Step>
  <Step title="Query enforced + audited" icon="file-search">
    Scope injected into CQL/JQL or checked post-fetch. One JSON audit line per call on stderr — credentials never logged.
  </Step>
</Steps>
