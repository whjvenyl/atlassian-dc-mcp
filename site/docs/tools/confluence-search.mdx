### Search

Search Confluence — pass **plain text** (auto-wrapped in `siteSearch`,
like the web UI) or a full **CQL** query. Your space allowlist is AND-ed
in automatically. Full query-language coverage: [CQL guide](/guides/cql).

<Callout type="info" title="Policy">
  `space in (...)` from your effective scope is appended; the response
  echoes `effectiveCQL` so you can verify what ran. `spacesFilter` is
  <b>intersected</b> with your scope — it can narrow, never widen.
</Callout>

| parameter | type | required | description |
|---|---|---|---|
| `query` | `string` | yes | plain text or CQL — auto-detected (`=`, `~`, `AND`, `ORDER BY`… mark CQL) |
| `cql` | `string` | no | explicit CQL — overrides query's auto-detection |
| `spacesFilter` | `string` | no | comma-separated space keys, intersected with your scope |
| `limit` | `number` | no | 1–100, default `20` |
| `start` | `number` | no | pagination offset, default `0` |

```json
{ "query": "deploy runbook" }
{ "query": "type = page AND label = runbook", "spacesFilter": "DOC,OPS", "limit": 10 }
```

Page forward with `start: nextStart` from the response.

<Callout type="tip" title="Scope first">
  Call `confluence_list_spaces` before searching — its `policySpaces`
  field is exactly the list your CQL gets intersected with.
</Callout>

### Search Users

Find Confluence users by name — before assigning comments or tracking
authors.

| parameter | type | required | description |
|---|---|---|---|
| `query` | `string` | yes | name or username substring |
| `limit` | `number` | no | 1–50, default `10` |

rules match on.
