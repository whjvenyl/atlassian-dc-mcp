### Search

Search Confluence with CQL — your space allowlist is AND-ed in
automatically. Full query-language coverage: [CQL guide](/guides/cql).

<Callout type="info" title="Policy">
  `space in (...)` from your effective scope is appended to your CQL; the
  response echoes `effectiveCQL` so you can verify what ran.
</Callout>

| parameter | type | required | description |
|---|---|---|---|
| `cql` | `string` | yes | CQL, e.g. `type = page AND label = runbook` |
| `limit` | `number` | no | 1–100, default `20` |

```json
{ "cql": "type = page AND title ~ \"runbook\"", "limit": 10 }
```

<Callout type="tip" title="Scope first">
  Call `confluence_list_spaces` before searching — its `policySpaces`
  field is exactly the list your CQL gets intersected with.
</Callout>

### List Spaces

scope.

|---|---|---|---|
