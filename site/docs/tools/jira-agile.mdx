---
title: Jira agile — boards, sprints, epics
description: Jira Software agile endpoints on Data Center — boards, sprints, epic membership.
---

These call `/rest/agile/1.0` — bundled with Jira Software on DC. Boards
and sprints can span projects, so **reads post-filter** issues to your
scope (out-of-scope rows are dropped, count reported as `filtered`), and
**writes check the board's owning project** when Jira reports one.

### Get Agile Boards

List boards with type and owning project.

| parameter | type | required | description |
|---|---|---|---|
| `type` | `string` | no | `scrum`, `kanban`, `simple` |
| `name` | `string` | no | name contains |
| `projectKeyOrId` | `string` | no | restrict to one project |
| `limit` | `number` | no | 1–50, default `25` |
| `startAt` | `number` | no | pagination offset |

***
