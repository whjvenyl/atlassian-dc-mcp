### Get Issue Links

Links on an issue with direction (`blocks`/`is blocked by`) and target.

<Callout type="info" title="Policy">
  The issue's project must be in your scope.
</Callout>

| parameter | type | required | description |
|---|---|---|---|
| `key` | `string` | yes | issue key |

***

### Create Issue Link

Link two issues by link-type name.

<Callout type="warning" title="Write tool">
  Write-gated; <b>both</b> issues' projects must be in your scope.
</Callout>

| parameter | type | required | description |
|---|---|---|---|
| `type` | `string` | yes | link type, e.g. `Blocks`, `Duplicate`, `Relates` |
| `inwardKey` | `string` | yes | issue at the inward end (`is blocked by X`) |
| `outwardKey` | `string` | yes | issue at the outward end (`blocks X`) |
| `comment` | `string` | no | comment on the outward issue |

```json
{ "type": "Blocks", "inwardKey": "SUP-123", "outwardKey": "PLAT-45" }
```

***

### Delete Issue Link

| parameter | type | required | description |
