---
title: Confluence pages
description: Get/create/update/delete/move/copy pages, page children, and version history.
---

Page bodies are **storage format** (Confluence XHTML), not Markdown —
`<h2>`, `<p>`, `<code>` etc.

### Get Page

Fetch a page — by numeric ID, or by **title + space** key.

<Callout type="info" title="Policy">
  Refused if the page's space is outside your scope — checked post-fetch.
</Callout>

| parameter | type | required | description |
|---|---|---|---|
| `pageId` | `string` | no | numeric page ID — or pass title + space |
| `title` | `string` | no | exact page title — requires `space` |
| `space` | `string` | no | space key — required with `title` |
| `expand` | `string` | no | expand list, default `body.storage,version,space` |
| `includeMetadata` | `boolean` | no | add history (creator, created) and labels |

```json
{ "pageId": "12345678" }
{ "title": "Runbook", "space": "DOC", "includeMetadata": true }
```

***

### Get Page Children

List child pages — children outside your scope are silently dropped.

| parameter | type | required | description |
|---|---|---|---|
| `pageId` | `string` | yes | parent page ID |
| `limit` | `number` | no | 1–100, default `25` |
| `start` | `number` | no | pagination offset |

***

### Get Descendants

Recursive page tree under a page — children of children, flattened.
Descendants outside your scope are dropped (count reported as `filtered`).

| parameter | type | required | description |
|---|---|---|---|
| `pageId` | `string` | yes | numeric page ID — the tree's root |
| `depth` | `string` | no | `all` (default) or `1` for direct children only |
| `limit` | `number` | no | 1–200, default `100` |
| `start` | `number` | no | pagination offset |

***

### Get Page Version

A page's body as it was at a specific version — pass the number from
`confluence_get_page_history`.

| parameter | type | required | description |
|---|---|---|---|
| `pageId` | `string` | yes | numeric page ID |
| `version` | `number` | yes | version number |

***

### Get Page History

Every version of a page — number, author, timestamp, comment.

| parameter | type | required | description |
|---|---|---|---|
| `pageId` | `string` | yes | numeric page ID |
| `limit` | `number` | no | 1–200, default `50` |

***

### Create Page

<Callout type="warning" title="Write tool">
  Refused when `allowWrites: false` or `confluence.readOnly: true`. Target
  space must be in your scope.
</Callout>

| parameter | type | required | description |
|---|---|---|---|
| `space` | `string` | yes | target space key |
| `title` | `string` | yes | page title |
| `body` | `string` | yes | storage format (XHTML) |
| `parentId` | `string` | no | creates as child of that page |

```json
{ "space": "DOC", "title": "Runbook", "body": "<p>Restart procedure…</p>", "parentId": "12345678" }
```

***

### Update Page

Update title and/or body — version auto-bumps.

<Callout type="warning" title="Write tool">
  Write-gated; page's space must be in your scope.
</Callout>

| parameter | type | required | description |
|---|---|---|---|
| `pageId` | `string` | yes | numeric page ID |
| `title` | `string` | no | new title (omit to keep) |
| `body` | `string` | no | new body, storage format (omit to keep) |
| `versionComment` | `string` | no | comment stored on this version |
| `isMinorEdit` | `boolean` | no | skips watcher notifications |

***

### Delete Page

Moves the page to trash (recoverable by a space admin on DC).

<Callout type="warning" title="Write tool">
  Write-gated; page's space must be in your scope.
</Callout>

| parameter | type | required | description |
|---|---|---|---|
| `pageId` | `string` | yes | numeric page ID |

***

### Move Page

Re-parent a page under a different parent (same space).

<Callout type="warning" title="Write tool">
  Write-gated; both pages' spaces must be in your scope.
</Callout>

| parameter | type | required | description |
|---|---|---|---|
| `pageId` | `string` | yes | page to move |
| `newParentId` | `string` | yes | new parent page ID |

***

### Copy Page

Duplicate a page — title required, optionally under a different parent.

<Callout type="warning" title="Write tool">
  Write-gated; the space must be in your scope.
</Callout>

| parameter | type | required | description |
|---|---|---|---|
| `pageId` | `string` | yes | source page ID |
| `title` | `string` | yes | title for the copy |
| `destinationParentId` | `string` | no | default: same parent as source |
