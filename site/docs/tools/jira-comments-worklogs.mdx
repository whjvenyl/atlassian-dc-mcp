### Get Comments

Comment list on an issue — author, timestamp, body.

<Callout type="info" title="Policy">
  The issue's project must be in your scope.
</Callout>

| parameter | type | required | description |
|---|---|---|---|
| `key` | `string` | yes | issue key |
| `limit` | `number` | no | 1–100, default `50` |

***

### Get Changelog

Field-change history — who changed status/fields and when. Covers
transitions, edits, reassignments.

| parameter | type | required | description |
|---|---|---|---|
| `key` | `string` | yes | issue key |
| `limit` | `number` | no | 1–100, default `50` |

***

### Add Comment

<Callout type="warning" title="Write tool">
  Write-gated; issue's project must be in your scope.
</Callout>

| parameter | type | required | description |
|---|---|---|---|
| `key` | `string` | yes | issue key |
| `body` | `string` | yes | comment text (plain) |
| `visibility` | `string` | no | JSON, e.g. `{"type":"group","value":"jira-users"}` |

```json
{ "key": "SUP-123", "body": "Triaged: High, assigned to alice." }
```

***

### Edit Comment

### Add Worklog

Log time on an issue.

<Callout type="warning" title="Write tool">
  Write-gated; issue's project must be in your scope.
</Callout>

| parameter | type | required | description |
|---|---|---|---|
| `key` | `string` | yes | issue key |
| `timeSpent` | `string` | yes | Jira format: `1h 30m`, `1d`, `30m`, `4h` |
| `comment` | `string` | no | worklog comment |
| `started` | `string` | no | ISO start time — default now |
| `remainingEstimate` | `string` | no | e.g. `2h` |
| `originalEstimate` | `string` | no | e.g. `1d` |

```json
{ "key": "SUP-123", "timeSpent": "1h 30m", "comment": "Root cause found" }
```
