---
title: Confluence spaces
description: Space listing, detail, and content browsing — all scope-checked.
---

### List Spaces

All Confluence spaces visible to your PAT, filtered to your effective
scope. `policySpaces` in the response is exactly the list your
`confluence_search` CQL gets intersected with.

| parameter | type | required | description |
|---|---|---|---|
| `limit` | `number` | no | 1–200, default `50` |

***

### Get Space Detail

Full detail on one space — name, type, description, homepage ID.

<Callout type="info" title="Policy">
  The space must be in your scope.
</Callout>

| parameter | type | required | description |
|---|---|---|---|
| `space` | `string` | yes | space key, e.g. `DOC` |

***

### Get Space Content

List content in a space — pages, blogs, or all types.

<Callout type="info" title="Policy">
  The space must be in your scope.
</Callout>

| parameter | type | required | description |
|---|---|---|---|
| `space` | `string` | yes | space key |
| `type` | `string` | no | `page`, `blogpost`, `comment`, `attachment` — omit for all |
| `limit` | `number` | no | 1–100, default `25` |
| `start` | `number` | no | pagination offset |
