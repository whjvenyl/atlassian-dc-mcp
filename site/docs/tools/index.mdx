Every tool runs under the [policy](/policy): scope checks apply to reads,
and writes additionally require `allowWrites: true` (and no `readOnly` on
that service). Write tools stay registered when writes are off but refuse
with an explanatory error — agents see the reason, not a missing tool.

## What agents see

The MCP `instructions` explain the scope model to agent clients and tell
them **not** to retry denied calls to work around the policy. Denied calls
return an error naming the reason — e.g. which spaces the caller *is*
allowed into.
